# 🎬 Amazon Prime Video Power BI Dashboard

An interactive **Power BI dashboard** designed to analyze Amazon Prime Video content. The project explores **Movies & TV Shows, genres, ratings, countries, release trends, and content popularity** through interactive visualizations and KPIs.

### 🛠️ Tools Used

**Power BI | Power Query | DAX | Python | Pandas | NumPy**

### 📊 Key Features

* Movies vs TV Shows analysis
* Genre and country-wise insights
* IMDb & TMDB ratings analysis
* Content trends over time
* Popularity and performance analysis
* Interactive filters and dashboards
